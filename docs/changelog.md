## 0.1.0.dev0

此开发版本包含 P0 至 P6 的成果。阶段编号对应实施计划中的工程里程碑。

| 阶段 | 更新内容 |
| --- | --- |
| P0–P2 | 验证 MaaCore SingleStep 契约，提供本地 stdio MCP 和 Mock，接通真机截图、单步战术、暂停和继续。 |
| P3 | 支持原格式 Copilot JSON 单文件执行、独立进程校验、进度查询和取消。 |
| P4 | 新增持久战斗上下文、按名称连续动作、结构化观察和经视觉验证的绝对倍率设置。 |
| P5 | 作业执行到安全同步点时可让出控制权。Agent 可行动、跳过或替换后续步骤，并恢复原作业。 |
| P6 | 提供 Windows x64 Release 的 `battle-v1` 构建及本地资源生成。战斗资源从 260.6 MiB 降至 53.2 MiB，减少 79.6%。源码包和 wheel 增加逐文件来源与许可审计。 |

P6 通过 65 项普通测试、5 项无设备原生测试和 24 帧固定截图回归。MuMu 实机在普通 1-7 演习中验证了接管、部署、技能、撤退、恢复、暂停和断开。证据见 [P6 验收](p6-acceptance.md)。

本版本提供独立的使用说明、版本更新和路线图。待完成的验收项见 [开发路线图](roadmap.md)。
