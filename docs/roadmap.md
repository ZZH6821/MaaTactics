# 开发路线图

## 当前基线

Windows x64 已完成 P6 精简构建和验收，实机场景为 MuMu 国服普通 1-7 演习。各阶段的结果见 [实施状态](implementation-status.md) 和 [版本更新](changelog.md)。

## 发布前验收

- **补齐 P2 稳定性测试。** 至少完成 10 轮有人工或 Agent 证据确认的独立实机场景，记录连续动作、截图新鲜度、游戏内生效及失败原因。核查停止后没有新输入，并确认 Worker 正常退出。
- **补充异常场景证据。** 覆盖 ADB 断连、任务卡住、原生进程异常退出和取消。实机测试继续显式启用。

## 后续验证

- **扩大战斗观察样本。** 补充其他地图、干员和皮肤，以及非零镜头偏移的实机画面。按字段记录误报、漏报、`unknown` 比例与延迟，完成 Ready 校准后再评估自动释放技能。
- **验证自动编队和更多作业。** 先完成自动编队的实机成功路径，再逐项扩展关卡覆盖并验证接管恢复。
- **评估精确过帧。** 先取得可验证的游戏帧反馈，再验证键位触发后的实际帧数。相关限制见 [MuMu 键位调研](mumu-keymap-research.md)。
- **评估原生运行时分发。** 确认各 DLL 和资源的来源、许可及对应源码要求后，再决定原生包的分发范围。当前构建方式见 [P6 构建和验收](p6-acceptance.md)。

阶段设计、依赖和验收细则见 [架构与实施计划](implementation-plan.md)。
